COMMAND 1: git branch -a
------------------------
List all branches (local and remote)

Output:
* main
  remotes/origin/main

Explanation:
- * main (asterisk indicates current active branch)
- remotes/origin/main (remote tracking branch on GitHub)


COMMAND 2: git branch -v
------------------------
List branches with their latest commit info (verbose)

Output:
* main e3ab2a1 Add pull request verification and fork repository documentation

Explanation:
- main = branch name
- e3ab2a1 = commit hash (short form)
- Add pull request verification and fork repository documentation = latest commit message


COMMAND 3: git branch -vv
-------------------------
List branches with verbose tracking information

Output:
* main e3ab2a1 [origin/main] Add pull request verification and fork repository documentation

Explanation:
- main = branch name
- e3ab2a1 = commit hash
- [origin/main] = upstream branch being tracked
- Rest = latest commit message

RECOMMENDED BRANCH OPERATIONS:
==============================

View all branches with status:
  $ git branch -a

Check branch tracking:
  $ git branch -vv

Update remote tracking:
  $ git fetch origin

Pull latest changes:
  $ git pull origin main

Create new branch:
  $ git checkout -b feature/new-feature

Delete merged branch:
  $ git branch -d branch-name

Push branch to remote:
  $ git push origin branch-name

Compare branches:
  $ git diff main..other-branch
